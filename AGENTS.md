# AGENTS.md

## Before working on the extension

This repo is a pi extension. Before you change extension code, read:

1. [`extensions.md`](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/extensions.md):
   the extension API, lifecycle, and conventions. Read it in full.
2. The rest of the
   [pi coding-agent docs](https://github.com/earendil-works/pi/tree/main/packages/coding-agent/docs):
   follow every cross-reference from `extensions.md` that touches your change
   (e.g. `tui.md` for UI components, `keybindings.md` for key handling).

You're done with this step when you can name the API surface your change
touches and the doc section that defines it.
